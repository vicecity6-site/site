Privacy Policy

GTA6 Clips Uploader · Last updated: November 11, 2026

GTA6 Clips Uploader ("the tool") is an internal application operated by Daniel to upload videos to YouTube channels that he owns. This policy explains what data the tool accesses and how it is handled.

Data the tool accesses

When the owner connects his Google account, the tool receives OAuth access and refresh tokens that allow it to manage videos on the owner's own YouTube channels. It uses the YouTube Data API only to upload videos and to set their title, description, tags and publish time.

The tool does not access, collect or store personal data of any other person, including YouTube viewers or commenters.

How data is stored

OAuth tokens are stored encrypted on the owner's private server and are used only to perform uploads requested by the owner. Video files are deleted from the server automatically within a few days after processing.

Sharing

No data is sold, shared with or transferred to third parties. Video files and their text are sent only to YouTube for upload, and to AI processing services (speech-to-text and text generation) used solely to prepare subtitles and descriptions.

Google API Services

The tool uses YouTube API Services. By using it you are also bound by the YouTube Terms of Service. See the Google Privacy Policy. The tool's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Access can be revoked at any time at Google Account permissions.
